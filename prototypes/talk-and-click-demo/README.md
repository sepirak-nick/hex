# Talk and click demo

A small React page for trying Labs › Talk and click.

```sh
npm install
npm run agentation   # Agentation's server, on port 4747
npm run dev          # this page, on http://localhost:5199
```

Turn on Labs › Talk and click in Hex, open the page, start a dictation, talk and
click things, then finish it. The notes appear in the toolbar, and an agent reads
them through Agentation's MCP tools. To use it in your own app, add the `<script>`
line from `index.html` in development only.
